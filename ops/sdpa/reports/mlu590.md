## 2. 实现选择

### 2.1 不可用 / 不优先路径（实测）

| 尝试 | 结果 |
|---|---|
| `aten::_scaled_dot_product_efficient/flash/cudnn_attention` | MLUFallback 到 CPU 后 `NotImplementedError` |
| Python `F.sdpa` 作为 backend 内部调用 | A1 注册 `AutogradPrivateUse1` 后经 dispatcher 递归（同 p800 教训） |
| 仅用 math private 作主路径（早期版本） | 未融合复合，相对原生 **0.11-0.55x**（4k 低至 0.12x） |
| FlagGems `_cambricon` Triton attention | 精度 265/265，但比原生慢 **10-40x**——仅兜底 |

### 2.2 关键更正（2026-09-23）

原生 `F.sdpa` **并不走 math**，profiler 显示其 dispatch 到：

```
aten::_scaled_dot_product_fused_attention_overrideable
  → RegisterMLU.cpp → cnnlFlashAttentionForward_v2
```

math private 是另一条未融合分解路径——这才是早期 0.12-0.52x 缺口的根因。

### 2.3 最终路径（分层）

```
业务 F.sdpa → A1 AutogradPrivateUse1
  → mlu590.sdpa_triton
       ① TMO fast path（fp16/bf16，SDPA_MLU_TMO=0 可关）
          torch_mlu_ops.flash_attention → cnnlScaledDotProductAttn_v7
       ② fused overrideable（P0 主路径 / fp32 / TMO 失败兜底）
          aten::_scaled_dot_product_fused_attention_overrideable
       ③ math private → ④ FlagGems → ⑤ fp32 reference
```

- **bool mask**: 转 additive `-inf` bias（fused/math 均不接受 bool）
- **causal+mask**: 先折叠进 mask 再调 private 入口
- **GQA**: overrideable 无 `enable_gqa` → `repeat_interleave` 扩 KV heads；
  TMO 在 BSHD head 维做同样扩展
- **全遮蔽行**: 输出端 `masked_fill` 恢复 NaN
- **可微直调**: `requires_grad` 走 `_SDPA_A1_Function` 数学 backward
  （TMO/overrideable 无完整 Python autograd）

## 3. A1 注册

| 项 | 结论 |
|---|---|
| dispatch key | `AutogradPrivateUse1`（与 torch_npu 同；`AutogradMLU`/`MLU` 亦可命中） |
| register 守卫 | 放宽为 torch_npu **或** torch_mlu 可用 |
| autograd | 统一数学 backward；dq/dk/dv 与原生子进程对照 max_err ≤ 6.1e-5 |
| 拦截 | op 层 count>0；注册路径与直调路径逐位一致；framework 拦截 28 次 |

## 6. 关键平台发现

1. **原生 F.sdpa → fused overrideable（CNNL FA v2）**，不是 math；
   直调 math private 会拿到未融合分解，0.11-0.55x 原生。
2. `aten::_scaled_dot_product_fused_attention_overrideable` 是 MLU 上
   可用的 **第一方融合入口**（efficient/flash/cudnn 三个 private op 仍不可用）。
3. **TMO `torch_mlu_ops.flash_attention`**（CNNL SDPA v7，BSHD 布局）在
   半精度 prefill 上可再快 1.2-1.8x，与原生 attn_bias 形状为
   `(B,H,Sq,Skv)`。
4. math private / 早期实现对 **bool mask** 本栈 err≈0.19，必须转 additive。
5. FlagGems `_cambricon` attention 精度过黄金但慢 10-40x 且无 autograd。
6. A1 key = `AutogradPrivateUse1`；全遮蔽行需显式恢复 NaN。
7. `SDPA_MLU_TMO=0` 可强制只走 overrideable（对齐原生 FA v2）。
